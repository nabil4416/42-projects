## 🛠️ Build & Run

Each project has its own `Makefile` (for C) or `requirements.txt` (for Python).

### 🔹 For C projects
```bash
make        # compile the library or executable
make clean  # remove .o files
make fclean # remove binaries and libs
make re     # full rebuild
````

### 🔹 For Python projects

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
